# RedMira Telegram Countdown Bot

## Дата релиза
27 ноября 2026 года, 17:55:55, часовой пояс Europe/Chisinau.

## Что делает проект
- `/start` регистрирует пользователя и показывает кнопку открытия секундного таймера.
- Таймер работает в Telegram Mini App и обновляется на экране каждую секунду.
- В момент релиза бот рассылает подписчикам сообщение с двумя кнопками: iPhone (сайт) и Android (APK).
- Пользователь, который впервые нажмёт `/start` после релиза, сразу увидит эти две кнопки.
- `/release` показывает администратору оставшееся время.

## Что нужно заменить
В `index.html` замени:
- `IOS_URL` на настоящий адрес сайта для iPhone;
- `ANDROID_APK_URL` на прямую HTTPS-ссылку на APK.

Для бота задай переменные окружения:
- `BOT_TOKEN` — токен от @BotFather;
- `WEBAPP_URL` — HTTPS-адрес опубликованного `index.html`;
- `IOS_URL` — адрес сайта;
- `ANDROID_APK_URL` — прямая ссылка на APK;
- `ADMIN_ID` — числовой Telegram ID администратора.

## Запуск локально
Требуется Python 3.10+.

```bash
pip install -r requirements.txt
```

Windows PowerShell:
```powershell
$env:BOT_TOKEN="ВСТАВЬ_ТОКЕН"
$env:WEBAPP_URL="https://твой-домен/index.html"
$env:IOS_URL="https://твой-сайт"
$env:ANDROID_APK_URL="https://твой-сайт/redmira.apk"
$env:ADMIN_ID="ТВОЙ_TELEGRAM_ID"
python bot.py
```

## Публикация Mini App
`index.html` должен быть размещён на HTTPS-хостинге. В @BotFather настрой домен Web App для бота (Menu Button / Web App domain) на домен сайта. Затем укажи полный HTTPS-адрес страницы в `WEBAPP_URL`.

## Важно
- Не публикуй токен бота и не отправляй его посторонним. Храни его только в переменной окружения хостинга.
- Бот должен постоянно работать на сервере, чтобы отправить релизное уведомление подписчикам.
- Если бот выключен в момент релиза, при следующем запуске он проверит дату и попробует разослать сообщение.
- Telegram не позволяет надёжно редактировать одно сообщение каждую секунду; поэтому точный секундный таймер показывается в Mini App, а не через частые правки сообщения бота.
- SQLite хранит список пользователей рядом с `bot.py`. Для постоянной работы используй хостинг с постоянным диском.
